# E-Commerce Website Project

This is a front-end E-Commerce website built using:

- HTML
- CSS
- JavaScript
- Local Storage

The project includes multiple pages such as homepage, product listing page, product details page, and cart page.

---

## Features

### Home Page
- Responsive navbar
- Search bar
- Category dropdown
- Recommended products section
- Clicking recommended products opens product details page
- Logo redirects to homepage
- "All Category" redirects to product listing page

---

## Product Listing Page
- Displays all products dynamically using JavaScript
- Category filtering from navbar
- Sidebar category filters
- Product cards with:
  - Image
  - Name
  - Price
  - Description
  - Wishlist button
  - Add to cart button
- Clicking product opens details page

---

## Product Details Page
- Displays selected product:
  - Image
  - Name
  - Price
  - Description
- Data fetched using localStorage

---

## Cart Page
- Add products to cart
- Remove products from cart
- Update quantity
- Display total price
- Cart data stored in localStorage

---

## Wishlist
- Add products to wishlist
- Wishlist stored in localStorage

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)
- LocalStorage API
- Font Awesome Icons
